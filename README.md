# 🎮 智能五子棋 · Smart Gomoku AI

一个基于威胁评分算法的智能五子棋游戏，**单 HTML 文件**，浏览器打开即玩。

## 快速开始

```bash
# 直接在浏览器打开
open gomoku.html

# 或启动本地服务器（推荐，PWA 功能需要）
python -m http.server 8080
# 访问 http://localhost:8080/gomoku.html
```

## 玩法

- 你执 **黑棋** 先行，AI 执 **白棋** 后手
- 点击棋盘交叉点落子
- 横、竖、斜任意方向 **五子连珠** 即获胜
- 支持悔棋、重新开始、计分

### 操作方式

| 操作 | 方式 |
|------|------|
| 落子 | 鼠标点击 / 触屏点击 |
| 重新开始 | 点击「🔄 重新开始」按钮 / 按键盘 `R` |
| 悔棋 | 点击「↩ 悔棋」按钮 / 按键盘 `U` |

## 🤖 AI 算法

AI 采用 **三级优先级决策 + 威胁评分系统**，不使用传统的 Minimax 搜索，在保证即时响应（<150ms）的同时具备较强的棋力。

### 决策流程

```
收集候选点（已有棋子周围 2 格内）
  │
  ├─ 能五连？──────── 立即获胜
  ├─ 对手能五连？──── 立即堵截
  └─ 综合评分每个候选点
       ├─ 进攻分 × 1.1（落 AI 棋子评估）
       ├─ 防守分 × 0.9（落对手棋子评估）
       ├─ 间隙模式识别（X_XXX / XX_XX）
       ├─ 双威胁加分（Fork 检测）
       └─ 中心位置加成
```

### 评分权重

| 模式 | 分数 | 说明 |
|------|------|------|
| 五连 | 10,000,000 | 获胜 |
| 活四 | 500,000 | 两端开放的四子 |
| 冲四 | 50,000 | 一端开放的四子 |
| 活三 | 30,000 | 两端开放的三子 |
| 眠三 | 3,000 | 一端开放的三子 |
| 活二 | 2,000 | 两端开放的二子 |
| 间隙四 | 50,000 | X_XXX / XX_XX 模式 |
| 双威胁 Fork | 200,000 × 威胁数 | 同时创造多个威胁 |

## 技术特性

- **纯前端**：仅一个 HTML 文件，零依赖
- **Canvas 渲染**：棋盘、棋子、动画
- **木纹背景**、**渐变棋子**、**落子高亮**
- **最后落子标记**、**获胜连线高亮**
- **PWA 支持**：可添加到手机主屏幕（需通过 HTTPS 访问）
- **响应式设计**：桌面和移动端均可流畅运行
- **键盘快捷键**：`R` 重开、`U` 悔棋
